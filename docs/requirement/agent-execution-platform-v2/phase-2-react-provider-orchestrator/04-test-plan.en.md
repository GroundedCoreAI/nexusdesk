## 1. Test Scope and Principles

**Scope**: Complete ReactAdapter contract and private ack-aware stream, private Outcome collection and deterministic fallback for protocol-free LocalTest, worker_emit/runtime_emit dual-emit isolation, first-emission gate and no-stream state machine, Execution Orchestrator, Worker old/new paths, synchronous ContextVar/asynchronous Runtime assembly, open event/SSE compatibility, errors/cancellation/timeout/Lease, real Memory, global flag, mixed deployment, and rollback; external Engines and Runtime Host are excluded.

**Principles**:

1. **Explicit parity rules**: Serial deterministic scripts strictly compare output/error/usage/history/dropped/stable payload/order/per-Run sequence/terminal/replay. Parallel tools compare call_id sets, local partial order, and model-round boundaries, canonicalizing only the paths in 03 section 7.3.
2. **Yield is not delivery**: The React test harness explicitly performs `anext→await worker_emit→acknowledge` on the public stream and uses Core-private `AcknowledgingEventStream` to verify identity/exactly-once/abort. LocalTest has no private protocol and retains pre-claim queueing, terminal discard, and yield=delivery; never conflate it with React no-stream behavior.
3. **One-way dual-emit boundary**: for_run/run receive only the same private runtime_emit; Factory/PlatformTools/RuntimeEngine cannot reach worker_emit. Orchestrator invokes the sole worker_emit only after public-stream retrieval, with spies recording every stage, order, and count.
4. **Flag and fingerprint are mandatory**: Default/explicit off uses legacy; enabled failure never falls back; the flag is excluded from fingerprint so off API/on Worker and mixed Workers do not produce configuration_changed.
5. **Both SSE APIs and real PG are mandatory**: Real Repository decides cancellation/Lease/success races and first-commit-wins; internal/Open independently verify durable events, transient delta, cursor replay, 200+ draining, tool.replay, and redaction.
6. **Deterministic asynchronous tests**: Use Events/gates/manual clocks; outer timeout only prevents hangs and real sleep never decides results. Every exit path asserts that all owned/test tasks are awaited/done.
7. **Private Outcome retains original codes**: Verify genuinely asynchronous `OutcomeCollectingAdapter` detection and descriptor fail-closed behavior. React collects privately exactly once through the shared public collector path, preserving completed/failed/cancelled semantics. LocalTest alone uses public collection followed by fixed public-error-code fallback; React never takes lossy fallback and Orchestrator never accesses `_execution`.
8. **No prewritten evidence**: T8's 06 records every primary test row independently; T11 seed cases are appended only after actual execution, and unexecuted/skipped/missing-environment work is never passed.

## 7. Defect Severity and Primary Test Exit Criteria

| Severity | Definition | Handling |
|---|---|---|
| P0 blocker | Reply/tool main flow broken; data loss; cross-tenant or credential disclosure; incorrect terminal overwrite; nil entering authorization/queries | Immediately disable new path, fix, and run complete regression |
| P1 severe | Old/new semantic mismatch; ack/SSE regression; cancellation/Lease failure; flag/rollback failure; Worker/Core reverse coupling; task leak | Must be fixed before rollout expansion or acceptance |
| P2 normal | Non-critical performance degradation, missing diagnostics, or non-sensitive field difference without compatibility impact | May be accepted with a recorded issue and product sign-off |
| P3 minor | Documentation, naming, or non-sensitive log issue | Schedule a fix |

**T8 primary-test exit**: Every P2-UT-01–24, P2-IT-01–20, and P2-CM-01–08 row has an actual result; every functional UT/IT/CM must pass, as must CM08's evidence-integrity/measurement-boundary portion.

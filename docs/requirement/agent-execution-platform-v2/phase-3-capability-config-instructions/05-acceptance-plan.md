## 1. 验收范围与责任

确认 AC 逐条达成，兼容、性能与快照判据有证据，客户端不可提权、敏感信息不泄露、开关可回退。默认由验收负责人组织并记录结论，执行人准备环境、执行补充检查和整理证据，两者可为同一人；不虚构产品、QA、业务、安全或运维等独立角色。开发者自验只证明符合本文需求，不冒称真实用户验收或独立审计。

## 2. 验收环境与前置条件

| 环境 | 用途 |
|---|---|
| 类生产环境（React + 受控模型/工具） | 功能验收、真实配置/性能指标与 Summary/Memory 回归 |
| 专用 PostgreSQL + LocalTestAdapter | 能力分层、启动屏障、失败/取消/超时、跨租户和快照验证 |
| quickstart 双容器（demo 模型） | 默认关闭、旧 React 执行和部署回退承诺验证 |
| disposable 存量库副本 | 在线迁移、并发读写、应用回滚；downgrade 仅在 disposable 库执行 |
| 前端验收构建 | Engine 配置、只读预览、i18n 与错误体验 |

**前置条件**：Phase 0 基线和 Phase 1–2 验收完成；`04-test-plan.md` 全部用例通过且无 P0/P1；实施时已重验迁移 head/down_revision；验收使用至少两个专用 tenant 和独立 scope，不与生产客户数据混用；所有快照与日志证据先经敏感扫描。

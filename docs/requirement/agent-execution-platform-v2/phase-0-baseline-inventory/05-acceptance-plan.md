## 1. 验收范围与责任

确认基线**真实可溯**、兼容样本**可重复加载**、回归结果**确定可复用**，并确认 Phase 1 可以在无 P0/P1 基线阻断项的条件下启动。

采用最小核心团队验收：只设验收负责人一名，可自行执行并作结论；确需协助时设执行人，允许与验收负责人为同一人。不设架构/产品/QA/研发/安全等多角色职责表，不设多角色签字表，不生成独立 UAT 轮次。开发者自验只代表符合已写需求，不冒称真实用户或独立审计。

阶段验收通过不构成后续阶段或任何高风险能力的启用授权；高风险能力启用须另附独立安全与运维批准记录。
